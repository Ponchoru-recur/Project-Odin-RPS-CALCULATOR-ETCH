# The Odin Project: JavaScript Basics Projects

The three JavaScript Basics projects from [The Odin Project](https://www.theodinproject.com/paths/foundations/courses/foundations), built with plain HTML, CSS and JavaScript.

Open `index.html` in a browser to pick a project, or open each folder's `index.html` directly using live server or something.

## Rock Paper Scissors (`rock-paper-scissors/`)

- Started as a console game (see the first commit), then reworked with a UI.
- Rock, Paper and Scissors buttons, a running score and round results shown on the page.
- Wins in the first 5

## Etch-a-Sketch (`etch-a-sketch/`)

- 16x16 (can be changed) grid of divs made with JavaScript and laid out with Flexbox.
- Hovering over a square colors it. (Can change too)

## Calculator (`calculator/`)

- Calculator that calculates numbers :>
- add, subtract, multiply, divide, operate functions etc.

### Keyboard shortcuts

| Key               | Action            |
| ----------------- | ----------------- |
| `0`-`9`, `.`      | Enter numbers     |
| `+` `-` `*` `/`   | Operators         |
| `Enter` or `=`    | Equals            |
| `Backspace`       | Delete last digit |
| `Esc` or `Delete` | Clear             |
